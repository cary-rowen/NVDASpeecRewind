# 语音回溯

语音回溯保存最近的 NVDA 语音，便于在焦点移动或语音被打断后重新听取之前的朗读内容。

## 功能

* 重复最后朗读的内容，或重复当前选中的语音历史记录项目。连按两次 `NVDA+x` 可在浏览模式下显示完整的语音历史记录，最新项目位于最前面。默认手势：`NVDA+x`。
* 将最后朗读的内容，或当前选中的语音历史记录项目复制到剪贴板。默认手势：`NVDA+control+x`。
* 查看语音历史记录中的上一项。未分配默认手势。
* 查看语音历史记录中的下一项。未分配默认手势。
* 移到语音历史记录中的上一个字符并读出。未分配默认手势。
* 读出语音历史记录中的当前字符。连按两次解释字符，连按三次读出字符的十进制和十六进制代码。未分配默认手势。
* 移到语音历史记录中的下一个字符并读出。未分配默认手势。

未分配默认手势的功能，请在“NVDA 菜单 > 选项 > 按键与手势”的“语音”类别中分配。

## 设置

打开“NVDA 菜单 > 偏好设置 > 设置 > 语音回溯”，可以启用语音历史记录、设置语音历史记录的最大项目数，或清除语音历史记录。

退出 NVDA 或在 NVDA 设置中清除语音历史记录后，记录会被清除。

## 要求和许可证

需要 NVDA 2026.3 或更高版本。
